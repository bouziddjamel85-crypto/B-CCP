# Gestion de mon compte / تسيير حسابي

تطبيق ويب بسيط لتسيير الحساب (رصيد، مداخيل، مصاريف) في ملف HTML واحد.

- البيانات تُحفظ محليًا في متصفح المستخدم (localStorage)
- يمكن تصدير/استيراد البيانات كملف JSON
- لا يحتاج أي خادم أو مكتبات خارجية

## التشغيل
افتح `index.html` مباشرة، أو عبر GitHub Pages.
